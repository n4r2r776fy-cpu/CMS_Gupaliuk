## 1. Ручні розрахунки

### Завдання 1: Переведення чисел N = 29 та F = 0.1

#### Переведення цілого числа $N = 29_{10}$:
* **У двійкову систему ($q = 2$):**
  * $29 / 2 = 14$ (остача **1**)
  * $14 / 2 = 7$ (остача **0**)
  * $7 / 2 = 3$ (остача **1**)
  * $3 / 2 = 1$ (остача **1**)
  * $1 / 2 = 0$ (остача **1**)  
  *Результат (остачі знизу вгору):* $29_{10} = 11101_2$

* **У вісімкову систему ($q = 8$):**
  * $29 / 8 = 3$ (остача **5**)
  * $3 / 8 = 0$ (остача **3**)  
  *Результат (остачі знизу вгору):* $29_{10} = 35_8$

* **У шістнадцяткову систему ($q = 16$):**
  * $29 / 16 = 1$ (остача **13** $\rightarrow \text{D}$)
  * $1 / 16 = 0$ (остача **1**)  
  *Результат (остачі знизу вгору):* $29_{10} = 1\text{D}_{16}$

#### Переведення дробу $F = 0.1_{10}$ у двійкову систему (6 знаків після коми):
* $0.1 \times 2 = 0.2 \rightarrow \text{ціла частина } \mathbf{0}$
* $0.2 \times 2 = 0.4 \rightarrow \text{ціла частина } \mathbf{0}$
* $0.4 \times 2 = 0.8 \rightarrow \text{ціла частина } \mathbf{0}$
* $0.8 \times 2 = 1.6 \rightarrow \text{ціла частина } \mathbf{1}$, залишок $0.6$
* $0.6 \times 2 = 1.2 \rightarrow \text{ціла частина } \mathbf{1}$, залишок $0.2$
* $0.2 \times 2 = 0.4 \rightarrow \text{ціла частина } \mathbf{0}$  
*Результат (цілі частини зверху вниз):* $0.1_{10} \approx 0.000110_2$
