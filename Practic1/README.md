### Завдання 3: Додавання чисел A = 60, B = 20 у 8-бітному додатковому коді

* $A = 60_{10} = 00111100_2$
* $B = 20_{10} = 00010100_2$

```text
  00111100  (60)
+ 00010100  (20)
----------
  01010000  (80)
```

* **Знакові біти доданків:** $0$ та $0$ (додатні числа).
* **Знаковий біт результату:** $0$ (додатне число).
* **Аналіз переповнення:** Оскільки обидва доданки мають знаковий біт $0$ і результат має знаковий біт $0$, **переповнення відсутнє (Overflow = False)**.
* **Перевірка в десятковій системі:** $01010000_2 = 64 + 16 = 80_{10}$.

### Завдання 4: Розбір числа C = 33.25 за стандартом IEEE 754 (Single Precision)

1. **Знак ($S$):** число додатне $\implies S = 0$.
2. **Модуль числа в двійковій системі:** $33.25_{10} = 100001.01_2$.
3. **Нормалізація:** $100001.01_2 = 1.0000101_2 	imes 2^5 \implies$ реальний порядок $p = 5$.
4. **Порядок зі зміщенням ($E$):** $E = p + 127 = 5 + 127 = 132_{10} = 10000100_2$ (8 бітів).
5. **Мантиса ($M$):** відкидаємо неявну одиницю $1.$ і доповнюємо $0000101$ нулями до 23 бітів:  
   $M = 00001010000000000000000_2$.
6. **32-бітне двоічне представлення:**  
   `0` `10000100` `00001010000000000000000` (HEX: `0x42050000`).

**Відновлення значення:**
$$(-1)^S 	imes (1.M)_2 	imes 2^{E - 127} = (-1)^0 	imes (1.0000101)_2 	imes 2^{132 - 127} = 1 	imes 1.0400390625 	imes 32 = 33.25$$

## 2. Код програми (C#)

```csharp
using System;
using System.Text;

class Program
{
    // --- Завдання 2: Функції-конвертери ---
    static string IntToBase(int n, int baseNum)
    {
        if (n == 0) return "0";
        char[] digits = "0123456789ABCDEF".ToCharArray();
        bool isNegative = n < 0;
        int curr = Math.Abs(n);
        string res = "";

        while (curr > 0)
        {
            res = digits[curr % baseNum] + res;
            curr /= baseNum;
        }

        return isNegative ? "-" + res : res;
    }

    static string FracToBin(double f, int precision = 6)
    {
        string res = "0.";
        double curr = Math.Abs(f) - Math.Truncate(Math.Abs(f));

        for (int i = 0; i < precision; i++)
        {
            curr *= 2;
            int bit = (int)curr;
            res += bit;
            curr -= bit;
        }

        return res;
    }

    // --- Завдання 3: 8-бітний додатковий код та переповнення ---
    static (string BinStr, sbyte SignedVal, bool Overflow) AddTwosComplement8Bit(sbyte a, sbyte b)
    {
        byte a8 = (byte)a;
        byte b8 = (byte)b;
        byte res8 = (byte)(a8 + b8);

        int signA = (a8 >> 7) & 1;
        int signB = (b8 >> 7) & 1;
        int signRes = (res8 >> 7) & 1;

        bool overflow = (signA == signB) && (signA != signRes);
        sbyte signedRes = (sbyte)res8;

        string binStr = Convert.ToString(res8, 2).PadLeft(8, '0');
        return (binStr, signedRes, overflow);
    }

    static void Main()
    {
        // Налаштування UTF-8 для відображення кирилиці в консолі
        Console.OutputEncoding = Encoding.UTF8;
        Console.InputEncoding = Encoding.UTF8;

        // Вхідні дані Варіанта №2
        int N = 58;
        double F = 0.3;
        sbyte A = 60, B = 20;
        float C = 33.25f;

        Console.WriteLine("=== Крок 2: Переведення N та F ===");
        Console.WriteLine($"N = {N} -> BIN: {IntToBase(N, 2)}, OCT: {IntToBase(N, 8)}, HEX: {IntToBase(N, 16)}");
        Console.WriteLine($"F = {F} -> BIN (6 знаків): {FracToBin(F, 6)}");

        Console.WriteLine("\n=== Крок 3: 8-бітне додавання A та B ===");
        var (binSum, decSum, ovf) = AddTwosComplement8Bit(A, B);
        Console.WriteLine($"A = {A}, B = {B} -> Сума бінарно: {binSum}, Десятково: {decSum}, Переповнення: {ovf}");

        Console.WriteLine("\n=== Крок 4: Розбір IEEE 754 для C ===");
        uint bits = BitConverter.SingleToUInt32Bits(C);
        string bitsStr = Convert.ToString(bits, 2).PadLeft(32, '0');
        
        string sign = bitsStr.Substring(0, 1);
        string exp = bitsStr.Substring(1, 8);
        string mantissa = bitsStr.Substring(9);
        float restored = BitConverter.UInt32BitsToSingle(bits);

        Console.WriteLine($"C = {C}");
        Console.WriteLine($"32 біти: {bitsStr}");
        Console.WriteLine($"Знак: {sign}, Порядок: {exp}, Мантиса: {mantissa}");
        Console.WriteLine($"Відновлене значення: {restored}");

        Console.WriteLine("\n=== Крок 5: Похибка представлення дробів ===");
        double v1 = 0.1, v2 = 0.2;
        double sumVal = v1 + v2;
        Console.WriteLine($"0.1 + 0.2 = {sumVal}");
        Console.WriteLine($"0.1 + 0.2 == 0.3: {sumVal == 0.3}");
    }
}
```

## 5. Контрольні запитання

1. **Чому ціле переводять діленням, а дріб — множенням на основу системи?**  
   Це пояснюється математичним розкладом числа за степенями основи $q$. Ціла частина складається з додатних степеней ($q^0, q^1, q^2 \dots$), тому ділення на $q$ зсуває розряди вправо та виділяє молодші цифри у вигляді остач. Дробова частина складається з від'ємних степеней ($q^{-1}, q^{-2} \dots$), тому множення на $q$ зсуває розряди вліво, перетворюючи найстарший дробовий розряд на цілу частину добутку.

2. **Як за додатковим кодом двох доданків визначити переповнення, не переводячи суму в десяткову систему?**  
   Переповнення (Overflow) виникає тоді і тільки тоді, коли знакові (найстарші) біти двох доданків однакові, але знаковий біт отриманої суми відрізняється від них (наприклад, додавання двох додатних чисел дає від'ємний результат).

3. **З яких трьох компонентів складається число у форматі IEEE 754 single і яка розрядність кожного?**  
   * **Знак (Sign):** 1 біт ($0$ — додатне, $1$ — від’ємне).
   * **Порядок / Експонента (Exponent):** 8 бітів (зі зміщенням 127).
   * **Мантиса (Mantissa):** 23 біти (з неявною старшою одиницею $1.M$).

4. **Чому вираз 0.1 + 0.2 == 0.3 дає хибний результат і як правильно порівнювати дробові числа?**  
   Десяткові числа $0.1$ та $0.2$ не мають точного скінченного двійкового представлення, тому при додаванні у форматі double виникає похибка округлення: `0.30000000000000004`. Порівняння дробів слід виконувати з врахуванням допустимої похибки $ arepsilon$: `Math.Abs(a - b) < 1e-9`.

## 6. Домашнє завдання

1. **Осмислення результату 1 (Похибка представлення дробів):**  
   Десятковий дріб $F = 0.3 = 3/10 = 3 / (2 	imes 5)$ містить у знаменнику множник 5. У двійковій системі числення скінченний вигляд мають лише ті дроби, знаменник яких є степенем двійки ($2^k$). Через це $0.3_{10}$ перетворюється на **нескінченний періодичний дріб** $0.0(010011)_2$, який при зберіганні в обрізаній мантисі неминуче втрачає точність порівняно з десятковим представленням.

2. **Осмислення результату 2 (Механізм додаткового коду):**  
   Для $k$-бітного регістра порозрядна інверсія бітів числа $N$ ($\sim N$) утворює число, де кожен біт доповнює початковий до $1$. Сума $N + \sim N$ дорівнює $2^k - 1$ (усі біти регістру дорівнюють 1). Додавши $1$, отримуємо додатковий код $(\sim N + 1)$, сума якого з початковим $N$ дає $N + (\sim N + 1) = 2^k$. Оскільки $k$-бітний регістр працює за модулем $2^k$, старша одиниця виходить за межі разрядності (в переповнення), а в регістрі залишається точний нуль ($2^k \equiv 0 \pmod{2^k}$). Отже, вираз $\sim N + 1$ поводиться як число $-N$.
